# 📰 NewsFlash - Modern News Website Landing Page

A sleek, modern, and fully responsive news landing page built using pure HTML5, CSS3, and JavaScript. Designed to deliver a fast and engaging reading experience across all devices.

---

## ✨ Features

- **Responsive Layout:** Perfectly styled for mobile, tablet, and desktop screens.
- **Breaking News Ticker:** Dynamic banner for high-priority news updates.
- **Categorized Sections:** Clean layout for Tech, Politics, Sports, and Entertainment news.
- **Interactive UI Elements:** Smooth navigation menu and clean typography.
- **Lightweight & Fast:** Built with pure Vanilla Web technologies—zero heavy frameworks or dependencies.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and content routing.
- **CSS3:** Custom Flexbox/Grid layouts and responsive styling.
- **JavaScript (ES6+):** Dynamic DOM manipulations and UI interactions.
